# Poojan Patel - Network Analysis Prompts

## Prompt 1 - PCAP Triage

Analyze the provided packet capture and perform an initial triage.

Identify:

- Top protocols
- Top talkers
- DNS activity
- HTTP activity
- External communications
- Suspicious indicators

Summarize findings in a structured investigation format.

---

## Prompt 2 - IOC Identification

Review the network traffic and extract potential Indicators of Compromise (IOCs).

Include:

- Domains
- IP addresses
- URLs
- HTTP methods
- Suspicious communication patterns

Provide confidence ratings for each IOC.

---

## Prompt 3 - Malware Traffic Investigation

Review the traffic and determine whether the observed behavior is consistent with malware activity.

Analyze:

- DNS requests
- Beaconing behavior
- HTTP POST activity
- External communications
- Command-and-control indicators

Provide supporting evidence and assessment.

---

## Prompt 4 - Attack Hypothesis Development

Based on the available network evidence, develop multiple attack hypotheses.

For each hypothesis provide:

- Supporting evidence
- Contradicting evidence
- Confidence level
- Final verdict

Prioritize hypotheses based on observed traffic patterns.

---

## Prompt 5 - Network Security Recommendations

Review the findings and recommend security controls that would have reduced risk.

Include:

- DNS controls
- Monitoring controls
- Endpoint protection
- Incident response recommendations
- Network architecture improvements
