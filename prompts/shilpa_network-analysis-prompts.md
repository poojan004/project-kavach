# Shilpa Soni - Network Analysis Prompts

## Prompt 1 - Traffic Review


Examine the packet capture and identify anything unusual.

Focus on:

- DNS lookups
- HTTP requests
- External destinations
- Unexpected communications

Highlight suspicious observations.

---

## Prompt 2 - Domain Investigation

Review all observed domains and identify those that appear suspicious.

Consider:

- Naming patterns
- Top-level domains
- Repeated lookups
- Malware-related behavior

Document findings with reasoning.

---

## Prompt 3 - Communication Analysis

Determine whether the host is communicating with external infrastructure in a suspicious manner.

Look for:

- Repeated connections
- HTTP POST requests
- DNS followed by communication
- Potential beaconing activity

Provide an assessment.

---

## Prompt 4 - IOC Collection

Create a list of indicators identified during the investigation.

Include:

- Domains
- IP addresses
- URLs
- Host information

Organize indicators in a format suitable for future investigations.

---

## Prompt 5 - Investigation Summary

Summarize the network investigation and explain:

- What was observed
- Why it is suspicious
- Potential impact
- Recommended next actions

Focus on practical conclusions supported by evidence.
