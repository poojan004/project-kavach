# Poojan Patel - Web Application Analysis Prompts

## Prompt 1 - Vulnerability Discovery

Analyze the target web application and identify security vulnerabilities that align with the OWASP Top 10.

For each finding provide:

- Vulnerability Name
- Risk Level
- Exploitation Method
- Business Impact
- Recommended Remediation

Include step-by-step testing guidance and expected evidence.

---

## Prompt 2 - SQL Injection Assessment

Review the application for SQL Injection vulnerabilities.

Focus on:

- Authentication forms
- Search functionality
- URL parameters
- API endpoints

Identify payloads that may demonstrate database interaction and explain the associated risks.

---

## Prompt 3 - Cross-Site Scripting Assessment

Analyze all user-input fields for possible XSS vulnerabilities.

Provide:

- Reflected XSS opportunities
- Stored XSS opportunities
- Example payloads
- Potential business impact
- Mitigation recommendations

---

## Prompt 4 - Authentication Review

Evaluate authentication controls and identify weaknesses related to:

- Password policies
- Account protection
- Session management
- Authentication bypass opportunities

Document all observations with supporting evidence.

---

## Prompt 5 - Executive Summary Generation

Based on identified findings, generate an executive-level security summary suitable for management review.

Include:

- Key findings
- Risk assessment
- Business impact
- Recommended actions
