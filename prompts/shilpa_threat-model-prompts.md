# Shilpa Soni - Threat Modeling Prompts


## Prompt 1 - Attack Scenario Review

Review the available evidence and describe how the attack most likely occurred.

Focus on:

- Entry point
- User actions
- Malware activity
- External communication

---

## Prompt 2 - Adversary Objectives

Determine what the attacker may have been trying to achieve.

Consider:

- Credential theft
- Information collection
- Malware deployment
- Persistence

Provide justification.

---

## Prompt 3 - Security Gap Identification

Review the attack path and identify missing or weak security controls.

Focus on:

- Email security
- Endpoint protection
- DNS controls
- Monitoring capabilities

---

## Prompt 4 - Risk Evaluation

Evaluate the risk associated with the observed attack.

Provide:

- Likelihood
- Impact
- Severity
- Business consequences

---

## Prompt 5 - Threat Model Summary

Create a concise threat model summary describing:

- Threat actor
- Attack path
- Affected assets
- Key risks
- Recommended mitigations
