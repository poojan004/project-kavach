## Project Overview

Project KAVACH is a multi-workstream cybersecurity engagement designed to simulate a real-world security assessment for a fictional NBFC organization, Meridian FinServe.

The engagement combines:

- Network Forensics
- Web Application Security Assessment
- Threat Modeling
- Defense-in-Depth Planning
- Secure Remediation
- Executive Security Reporting

The objective is to produce a reproducible investigation and assessment repository that allows an independent reviewer to understand:

- What was discovered
- How findings were validated
- Why findings are important
- How risks can be mitigated

---

## Engagement Objectives

### Network Security

- Analyze a malware-related packet capture
- Perform traffic triage
- Develop attack hypotheses
- Extract Indicators of Compromise (IOCs)
- Propose security architecture improvements

### Web Application Security

- Assess DVWA and OWASP Juice Shop
- Validate OWASP Top 10 vulnerabilities
- Document exploitation paths
- Propose remediation strategies
- Compare SAST results before and after remediation

### Security Architecture

- Build a joint threat model
- Develop a defense-in-depth strategy
- Produce executive-level security recommendations
